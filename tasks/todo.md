# SELTIVO backend: реалізація

> Уточнення: міграцію каталогу відкладено. Не змінювати `catalog.json` і поточне керування макетами під час створення акаунтів, заявок та чату.

Деталі контрактів, ризиків і меж: [plan.md](plan.md). Нижче збережено первісний чеклист для звірки, тому порожні позначки не відображають фактичний прогрес.

Поточний стан: API акаунтів, конфігурацій, заявок, чату, сповіщень, статусів, видалення клієнтського акаунта та аудиту реалізовано; Next підключений, списки мають пагінацію. Каталог лишається файловим за рішенням власника, ZIP-імпорт прибрано. Версійні міграції схеми (v1 → v3), логічний backup у R2, погодинне очищення застарілих копій, `DeletionLedger` і пробне відновлення на окремому staging Worker виконані й покриті автотестами. Перед фінальним запуском у production залишаються деплой актуального коду Worker у production, налаштування бойових секретів Brevo (`BREVO_API_KEY`, `BREVO_SENDER_EMAIL`), перевірка доставки листа відновлення пароля та налаштування алертів у Cloudflare dashboard.
